# 🚚 GoParcel - Parcel Delivery Management System

GoParcel is a full-stack MERN-based parcel delivery platform that enables users to book parcels, track deliveries, manage riders, and handle payments securely through Stripe. The system includes role-based dashboards for Admin, User, and Rider with real-time parcel management features.

## ✨ Features

### 👤 Authentication & Authorization

* Firebase Authentication
* JWT Protected Routes
* Role-Based Access Control (Admin, User, Rider)

### 📦 Parcel Management

* Create Parcel Booking
* Parcel Tracking System
* Delivery Status Updates
* Delivery Cost Calculation

### 🏍️ Rider Management

* Rider Application System
* Rider Approval/Rejection
* Assign Rider to Parcel
* Rider Delivery Dashboard

### 💳 Payment System

* Stripe Payment Integration
* Secure Online Payments
* Payment History Tracking

### 📊 Admin Dashboard

* User Management
* Rider Management
* Parcel Management
* Statistics & Analytics

### 🔍 Tracking System

* Unique Tracking ID Generation
* Real-Time Parcel Status Tracking
* Delivery History Timeline
